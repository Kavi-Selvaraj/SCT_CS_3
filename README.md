# Task 3 – Educational Keylogger

## Objective

To create a basic educational keylogger demonstration that records keyboard input within the designated application.

## Features

* Records keys typed in the application.
* Saves recorded keystrokes to a text file.
* Records special keys such as Space, Enter and Backspace.
* Includes timestamps for recorded keystrokes.

## Technologies Used

* Python

## How to Run

```bash
python keystrokes.py
```

## Output

The recorded keystrokes are stored in:

```text
keystrokes.txt
```

## Safety Note

This project is created for educational purposes. It is designed to demonstrate keyboard-event logging within a designated application and should only be used with the user's knowledge and consent.

## Conclusion

The project demonstrates the basic concept of keyboard-event handling and local logging using Python.
